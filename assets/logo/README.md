# Dutchman logo

Dutchman's own artwork, licensed with the rest of this repository under the
[Apache License, Version 2.0](../../LICENSE).

The mark is a single-masted ship. Its square sail is split at the mast: the left half is solid,
the closed native file; the right half is a wireframe, the open model Dutchman produces. The
lantern at the masthead is the one warm light.

| File | Use |
|---|---|
| `dutchman-mark.svg` | The mark on light grounds. |
| `dutchman-mark-night.svg` | The mark on dark grounds. |
| `dutchman-mark-mono.svg` | The mark in one ink, where colour is not available. |
| `dutchman-lockup.svg` | Mark and name on light grounds. |
| `dutchman-lockup-night.svg` | Mark and name on dark grounds. |
| `dutchman-lockup.png`, `dutchman-lockup-night.png` | The lockups rendered at 3× with the name set in Spectral, for places that cannot load the font (GitHub's README view). |

The lockup's name is set in [Spectral](https://github.com/productiontype/Spectral) SemiBold
(SIL Open Font License 1.1). The SVGs name the font and do not embed it; the PNGs were rendered
from them with Spectral installed.

Keep clear space of one hull height (a sixth of the mark's height) on every side. Use the mark at
16 px or larger and the lockup at 120 px wide or larger. Don't recolour, rotate, outline or shadow
the mark, separate the lantern, or place the mark on a photograph.
