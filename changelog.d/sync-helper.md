### Desktop app

- Add Dutchman Sync, a small tray (menu bar) program with its own launcher entry that keeps converted designs up to date: Pause, Add folder, Open Dutchman and Quit in its menu, a first-run window to choose a source and an output folder, desktop notifications when a design is updated or an update fails, an optional start at login, and one running copy. It shares one state file with the app.
