### Command line and install

- The Onshape fetch now says what it will cost before it spends it. It lists the document, which costs at most three calls, and estimates the calls the whole fetch needs; Onshape's Free plan allows 2,500 API calls a year. Above 50 estimated calls the command line asks y/N on a terminal and otherwise stops unless you pass `--yes` or an explicit `--max-calls N`; the MCP tool never prompts and returns the estimate with `onshape/approval` so the calling agent can ask its user. Cached replies cost no call and are not counted.
- Without `--max-calls` (or `max_calls` in the MCP tool), the limit after that go grows with the document's Part Studios, assemblies and parts, up to a ceiling of 2000 calls; `--max-calls N` is a hard ceiling nothing goes past.
- In the app, a fetch above 50 estimated calls asks "This document needs about N of your yearly Onshape API calls (2,500 on Free plans). Continue?" with Continue and Cancel. A fetch that stops at the request limit is shown as Stopped, not Failed: the Results card says how many calls were made and about how many more are needed and offers only Continue fetching, which asks the same way and carries on from the replies already fetched; the footer reads "0 converted, 1 stopped". The question appears centerd over the app window. Other fetch errors, and a crash during the fetch, end the job with a message too.
