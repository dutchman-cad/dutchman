### Reports

- Machine-readable names use American spelling: `replay.center`, `recognized, not read yet`, `neighbors` (MCP argument and report scope), `canceled` (status and reason) and `fillet-overflows-neighboring-face`. Dutchman writes the new names and still accepts the old spelling when it reads them (MCP arguments, report scopes, Fusion exporter status files). Scripts that match the old text should match the new one.
