### Assemblies

- Dutchman reads a placed-parts package from an optional module: STEP files placed by name with a 3 x 4 transform, plus flat overlays (copper, silkscreen) drawn as coloured sheet faces with holes on the part they name. A missing or unreadable file, an escaping file name and a bad overlay area are reported by name and the rest converts. The package format is in docs/modules.md.
