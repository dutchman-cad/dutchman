### Desktop app

- Update now only replaces an AppImage when this Dutchman is running from it. An AppImage path inherited from another app's terminal is ignored, so Dutchman offers the download instead.
- The portable Windows update only moves and deletes the files Dutchman's own package lists, parks the old ones as `.dutchman-old`, and keeps a list of them so your own `.old` files and `docs` or `skills` folders are left alone.
