### Assemblies

- A Fusion assembly from a bulk export now places the designs it inserts from the export folder: Dutchman reads the export's `manifest.json`, matches each insertion the file names to a listed design, reads that design's own `.f3d` and places it at the insertion's position. Give it the export folder or its zip, or the single `.f3d` in its folder. A reference that states a version places exactly that version (never the newest in its stead; a version the export moved aside is read from `Older versions/`, a deleted one is reported missing). Designs an assembly actually places are put inside it and not converted again as separate results (a design it lists but doesn't place stays a result; of assemblies that insert each other, the first stays a result and the plan says so), and a rebuilt `.f3z` beside an assembly's `.f3d` is converted instead of the `.f3d`. An insertion the file doesn't name a design for stays reported as missing.
