Dutchman Convert turns designs from other CAD programs into native SolidCraft designs, keeping as much of their feature history, sketches, and assemblies as it can. 0.2.1 reads big Fusion assemblies that 0.2.0 refused, brings much more Inventor history through verified, and can now run on a server: in Docker, from a browser, or watching a shared folder.

![A CC0 CAD Fixture Recipes Inventor part (P03a) converted by Dutchman 0.2.1 and open in SolidCraft: its extrusion and hole come through as editable features in the browser and the history timeline, and SolidCraft's rebuild matches the original](https://raw.githubusercontent.com/dutchman-cad/dutchman/v0.2.1/docs/images/releases/0.2.1/inventor-part-history.png)

## What's new

- **Big Fusion assemblies open.** Large multi-part machine assemblies and multi-document archives that 0.2.0 refused now convert: their edges that end slightly off their vertices are accepted, merged designs that reuse a parameter name no longer clash, and when a design's history can't be read, the geometry-only fallback now really leaves parameters out. On a private set of 87 popular models, refusals drop from 28 to 23.
- **Much more Inventor history, verified.** On the public CC0 CAD Fixture Recipes (78 Inventor parts), 47 now come through as editable history that SolidCraft rebuilds to match the original, up from none in 0.2.0, with 203 of 249 features mapped (was 103). New: full revolves, more hole forms (center-point, spotface, end targets), oriented chamfers, circular sweeps, two-section lofts, closed sketch splines, and sketch regions in the order SolidCraft expects.
- **Sheet metal and blends.** Bend-free Inventor plates map to SolidCraft sheet-metal base flanges, and fillets, chamfers, and corner rounds on edges an extrusion or a plate created now map too. When a blend can't be mapped, the report says which case it is.
- **Run it on a server.** Each release is published as a container image, `ghcr.io/dutchman-cad/dutchman` (amd64 and arm64), with the same binaries as the downloads. `dutchman-web` converts from any browser (in the Linux downloads and the image), with upload and disk limits, a private data folder, and protection against cross-site uploads; put it behind HTTPS beyond your own network.
- **Watch a folder.** `dutchman watch <inbox> --out-dir <dir>` converts whatever lands in a folder, such as a NAS share, with each report beside its design. It waits for copies to finish, never converts the same file twice, and never writes to the inbox.
- **Smaller things.** A one-part STEP file goes into the design exactly as it is. `dutchman formats` shows each format's published support level. Linux downloads now run on systems with glibc 2.36 or newer.

## Known issue

A few SolidWorks parts that 0.1.5 read still come out empty or with fewer bodies. Dutchman reports this as a loss, not as a clean conversion, and a fix is in progress. If 0.1.5 worked better for a part, keep using it for that part for now.
