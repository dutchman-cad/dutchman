Dutchman Convert turns designs from other CAD programs into native SolidCraft designs, keeping as much of their feature history, sketches, and assemblies as it can. 0.2.4 keeps the editable start of a history when a later feature cannot be mapped, converts more Fusion and Inventor designs, and keeps much more FreeCAD history, including helices, chained mirrors, and live spreadsheet formulas.

## What's new

- **Partial history instead of none.** When a feature cannot be mapped, the editable features before it are kept, hidden beside the imported final shape, and the report names the feature that stopped the history. Stored geometry converts as an imported base body with the mappable features after it.
- **More Fusion and Inventor designs convert.** Fusion designs whose sweeps or rotational supports failed the model checks convert now. Inventor holes are drilled the way they point, and work planes are read as datum planes. Fusion components the design hides open hidden, and assemblies of several designs group each design's features into a named timeline folder.
- **More FreeCAD history.** Helices convert as editable coils, mirrors chained with patterns convert as ordered mirror and pattern features, and spreadsheet formulas stay live expressions. Assemblies that link parts in other FreeCAD documents convert, and unused datum helpers are skipped.
- **Choose the SolidCraft version to target.** `--solidcraft-version x.y.z` (or `solidcraft_version` in MCP) sets the oldest SolidCraft the design must open in. Features that need a newer release keep the original geometry and say which version they need.
- **Progress while reading.** Reads and conversions show their stage, the designs read so far, and elapsed time. The desktop app shows a progress bar when the total is known.
- **One universal Mac command-line download.** A single archive now holds the command-line tools for Apple silicon and Intel, beside the universal desktop disk image.
- **Report this on GitHub works again.** Signed-in GitHub users could get "406 Not Acceptable" from a long filled-in report. The link is now kept short enough, and a report that does not fit is copied for you to paste.

## Known issue

A very large Fusion assembly can need more than 24 GB of memory to convert ([#227](https://github.com/dutchman-cad/dutchman/issues/227)); on a machine with less, the system stops the conversion before it writes anything.
