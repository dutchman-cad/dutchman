Dutchman Convert turns designs from other CAD programs into native SolidCraft designs, keeping as much of their feature history, sketches, and assemblies as it can. 0.2.2 makes self-hosting one step: SolidCraft and Dutchman on one address, with converted designs saved to a shared folder and opening straight in SolidCraft. It also keeps more of a Fusion assembly's joints, and installs on a Mac with Homebrew without Xcode.

## What's new

- **SolidCraft and Dutchman on one address.** A ready-to-run Compose example puts SolidCraft's web app at `/` and Dutchman at `/dutchman/` behind one proxy, with a watched inbox on a shared folder ([examples/compose](https://github.com/dutchman-cad/dutchman/tree/v0.2.2/examples/compose)). `dutchman-web` can now run under a path (`--base-path`) and save every converted design to a folder such as a NAS share (`--output-dir`).
- **Open in SolidCraft.** With `--solidcraft /`, each converted design in Dutchman Web gets an **Open in SolidCraft** link that opens it directly in the SolidCraft web app on the same address.
- **More of an assembly's joints.** Joints inside a component placed more than once, such as a printer's feet, are kept as that component's own joints instead of being left out, and joints to a part inside a design inserted into a component find that part. A component that is empty in its source is placed as an empty component, keeping its joints, instead of the whole design converting as stored geometry.
- **Merged designs keep their parameters straight.** When merged designs reuse a parameter name, each expression keeps following its own design's parameters to their new names.
- **More curved parts verified.** The SolidCraft replay check now allows for the error in SolidCraft's measuring mesh and compares body areas, so lofts, revolves, and other curved parts that rebuild exactly are verified instead of flattened.
- **Homebrew without Xcode, and the app too.** `brew install dutchman-cad/tap/dutchman` pours a ready-made bottle on macOS and Linux, so it no longer needs Xcode or current Command Line Tools. `brew install --cask dutchman-cad/tap/dutchman-convert` adds the app to Applications and Launchpad, where it now shows as **Dutchman**.

## Known issue

A few SolidWorks parts that 0.1.5 read still come out empty or with fewer bodies. Dutchman reports this as a loss, not as a clean conversion, and a fix is in progress. If 0.1.5 worked better for a part, keep using it for that part for now.
